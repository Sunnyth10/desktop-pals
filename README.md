# DeskPals Website 🐾

Marketing and showcase website for **DeskPals** (v1.1.0) — tiny animated desktop companions that live on top of everything you do.

🌐 **Live Deployed Website**: [https://desktop-pals-two.vercel.app](https://desktop-pals-two.vercel.app)

- `index.html`: Production-ready single-page website with clean URLs, responsive design, interactive demo, dynamic GitHub release download counters, and social preview cards.
- `images/`: High-resolution companion artwork (`cat.png`, `fox.png`, `robot.png`, `web-hero.png`, `ghost.png`, `logo.png`, `tray.png`), `dashboard.png`, and `og-hero.png`.
- `vercel.json`: Vercel edge rewrite configuration.

## Deployments
- **Production URL**: [https://desktop-pals-two.vercel.app](https://desktop-pals-two.vercel.app)
- **GitHub Repository**: [https://github.com/Sunnyth10/desktop-pals](https://github.com/Sunnyth10/desktop-pals)
