# DeskPals Website

Marketing and showcase website for **DeskPals** (v1.1.0) — tiny animated desktop companions that live on top of everything you do.

- `website/index.html`: Fully enhanced, zero-placeholder, production-ready single-page website.
- `website/images/`: High-resolution companion artwork (`cat.png`, `fox.png`, `robot.png`, `web-hero.png`, `ghost.png`, `logo.png`, `tray.png`) and the `dashboard.png` showcase screenshot.

## Local Preview
Run any local static HTTP server (e.g., `python3 -m http.server 8085`) and navigate to `http://localhost:8085/website/`.
