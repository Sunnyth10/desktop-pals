# DeskPals Website

Production-ready marketing and documentation website for **DeskPals** (v1.1.0).

- Ready to deploy: open `index.html` locally in any browser or host on Netlify, Vercel, GitHub Pages, Cloudflare Pages, or your own server.
- Built-in assets in `images/`: high-resolution companion renders (Cat, Fox, Robot, Web Hero, Ghost), logo, and the v1.1.0 Wellness & Productivity Dashboard preview.

## Pages & Routes (Hash Links)
- `#home`: Hero desk with live physics companions, quick explore cards, feature dashboard preview, real desktop screenshots, and testimonials.
- `#why`: Why desktop companions make work lighter, interactive hide/cheer/performance demo toys.
- `#dashboard`: Showcase for the Pomodoro Timer Engine, Smart Task Manager, 7-Day Sparklines, 52-Week Contribution Heatmap, Smart Reminders, and Distraction Shield.
- `#meet`: Interactive companion stage & mood animator (Cat, Fox, Robot, Ghost, Web Hero) with Cheer, Nap, Spin, and Snack routines.
- `#collections`: Browse and import companion packs (Space crew, Snack time, Critters) with shareable `PAL1-...` codes.
- `#how`: 3-step quick start installation guide.
- `#pricing`: 100% Free & Open Source licensing (MIT License).
- `#faq`: Comprehensive FAQ answering system requirements, performance targets (<150 MB RAM, <3% CPU), click-through physics, multi-pal roaming, and 100% offline-first privacy.

## Installer Links & Settings (v1.1.0)
In `<script>` near the bottom of `index.html`:
- `DOWNLOADS.win`: Windows x64 `.exe` installer (Release v1.1.0)
- `DOWNLOADS.macArm`: macOS Apple Silicon `.dmg` (Release v1.1.0)
- `DOWNLOADS.macIntel`: macOS Intel `.dmg` (Release v1.1.0)
- `USERS`: Download and community count counter animation.
